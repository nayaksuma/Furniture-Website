# Furniture Website

## About the Project
The Furniture Website is a front-end web application designed to showcase furniture products through a simple, attractive, and user-friendly interface. Users can explore furniture items, view product details, access the cart page, and navigate through login and payment pages.

## Features
- Attractive home page
- Furniture product display
- Product images
- Shopping cart page
- Login page
- Payment page
- Thank you page
- Simple and user-friendly interface
- Responsive design (if implemented)

## Technologies Used
- HTML5
- CSS3

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Double-click `index.html` or open it in your web browser.
5. Explore the Furniture Website.
